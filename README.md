FoodRescue – Food Donation and Surplus Food Management System

About the Project

FoodRescue is a web-based application designed to reduce food wastage by connecting people who have surplus food with those who need it.

The main objective of this project is to encourage food donation, promote food reuse, and help ensure that surplus food is utilized instead of being wasted.

 Objectives

- Reduce food wastage.
- Encourage food donation.
- Connect food donors with people in need.
- Provide an organized platform for surplus food management.
- Promote social responsibility and environmental sustainability.

Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Python (Flask)
- **Database:** MySQL
- **Development Tool:** Visual Studio Code

Project Overview

FoodRescue provides a web-based platform for managing surplus food donations. It aims to simplify the food donation process through a user-friendly interface and a backend system that manages application data.

Key Features

- User-friendly web interface.
- User login and authentication.
- Food donation management.
- Surplus food information management.
- Database integration.
- Organized management of food donation records.

 Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/UppuVaishnavi/Food_Rescue.git
   ```

2. Open the project folder in Visual Studio Code.

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the virtual environment:

   **Windows PowerShell:**
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

6. Configure the MySQL database according to your project configuration.

7. Run the Flask application using the appropriate application entry-point file.

8. Open the local website in your browser.
